Training

Network: 3 × [3×3 conv → batch norm → ReLU → 2×2 max-pool] with 8, 16, 32 channels, then one fully connected layer (9,416 weights for 7 classes). Adam with a cosine learning-rate schedule, class-weighted cross-entropy, random flips and 90° rotations. The epoch with the best validation macro-F1 is kept.

INT8 quantization

Batch norm is folded into the convolutions. Weights become signed 8-bit values with one scale per output channel; activations become unsigned 8-bit values. Each layer's output is rescaled with a 16-bit multiplier and a right shift, exactly as the accelerator's requantizer does, and pooling is applied before requantization. Accuracy below is computed with the bit-exact integer model, so it is the accuracy the chip will give.

Download weights

One .zip with the same folders as the project: hardware_weights/ (15 .mem files, ROM images and manifest), rtl/generated/ (pcb_cfg_pkg.sv, pcb_param_rom.sv), checkpoints/quantized_model.npz, the float weights and a training report. Copy the folders over the project and re-run simulation.

Classify an image

Runs the INT8 integer model, the same arithmetic as the RTL, so the scores are the values inside the chip. Pick a sample or upload your own image. Uses the pre-trained project model.
